# /humanize - AI文章人間化・自然化

## 概要
AIが生成した文章から「AI臭さ」を除去し、人間が書いたような自然な文体に変換します。日本語特有の不自然さ（接続詞過多・漢字比率・定型句・読点）に特化し、多言語にも対応。

## 統合元スキル
- `humanizer` v2.5.1 / v2.8.0 (AIパターン除去・実声付与)
- `stop-slop` (予測可能なAIテル除去)
- `stop-ai-slop-jp` (日本語特化: 全角ダッシュ・主体不在・命題型H2・壮大化・両論併記・リズム均一)
- `natural-japanese-writing` (接続詞削減・漢字比率調整・定型句置換・読点適正化)
- `grammar-check` (文法・論理・フローチェック・対象絞込修正提案)

## 使い方

```
/humanize                     # 対話式で変換
/humanize <テキスト>           # 直接指定で変換
/humanize --file=<パス>        # ファイル指定で変換
/humanize --lang=<言語>        # 言語指定 (ja/en/zh/ko)
```

## 変換ルール（日本語特化）

### 除去・置換パターン

| カテゴリ | AI典型パターン | 人間的表現へ |
|---------|--------------|-------------|
| 接続詞 | 「また」「さらに」「そして」「しかし」「したがって」過多 | 文脈で暗示・短文分割・逆接の使い分け |
| 主体 | 主語なき受動態・無主語文 | 明確な主体・能動態 |
| 定型句 | 「重要なのは」「注目すべきは」「鍵となるのは」 | 具体的な名詞・動詞で置換 |
| 命題型H2 | 「〜とは」「〜の重要性」「〜のメリット」 | 疑問形・動詞始まり・ベネフィット先行 |
| 壮大化 | 「革命的な」「画期的な」「究極の」 | 具体的な数値・事例・比較 |
| 両論併記 | 「メリットもあればデメリットもある」 | 明確なスタンス・判断根拠提示 |
| リズム | 全文同じ句読点間隔・文長 | 緩急・短文混在・リズム変化 |
| 漢字比率 | 漢字過多（難解）または平仮名過多（幼稚） | 専門用語は漢字・接続は平仮名・バランス調整 |

### チェック項目（grammar-check統合）

1. **文法**: 主述関係・助詞・時制・敬語整合
2. **論理**: 前提→結論の飛躍・循環論証・因果関係の曖昧さ
3. **フロー**: 段落間接続・情報の新旧構造・読者の認知負荷

## ワークフロー

### Phase 1: 分析
```
入力テキスト → AIパターン検出 → 問題箇所マーキング → 重要度順ソート
```

### Phase 2: 変換提案
```
各問題箇所に対して:
  - 原文
  - 修正案（複数パターン提示可）
  - 修正理由
  - 影響度（高/中/低）
```

### Phase 3: 適用・確認
```
ユーザー選択 → 一括/個別適用 → 結果表示 → 差分確認
```

### Phase 4: 学習
```
適用パターン → taste/メモリ蓄積 → 次回からの精度向上
```

## オプション

| オプション | 説明 |
|-----------|------|
| `--lang` | 対象言語 (ja/en/zh/ko) default: ja |
| `--level` | 変換強度 (light/normal/deep) default: normal |
| `--file` | 入力ファイルパス |
| `--output` | 出力ファイルパス |
| `--check-only` | 変換せず問題箇所レポートのみ |
| `--preserve` | 保持したい表現・用語（カンマ区切り） |
| `--learn` | 変換パターンを学習 |

## 使用例

```
/humanize "AIが書いた文章です。また、重要なのは..."
/humanize --file=draft.md --level=deep --output=humanized.md
/humanize --check-only --lang=ja
/humanize "英語の文章も対象" --lang=en
```

## 言語別プリセット

| 言語 | 重点対策 |
|------|---------|
| `ja` | 接続詞・主体・定型句・漢字比率・読点・敬語 |
| `en` | Passive voice・hedging・corporate speak・transition overload |
| `zh` | 成语过多・被动语态・连接词堆砌 |
| `ko` | 수동태・격식체・연결어미 과용 |

## 品質基準
- **自然さ**: ネイティブが「AIっぽい」と感じない
- **意図保持**: 元の意味・ニュアンスを損なわない
- **最小変更**: 必要な箇所のみ修正（Surgical Changes）
- **学習**: ユーザーの修正嗜好を蓄積し精度向上
