# /interview-script - JTBDインタビュースクリプト生成

## 概要
**Jobs-to-be-Done (JTBD)** フレームワークに基づき、採用面接・ユーザーインタビュー・ステークホルダー調査等の構造化スクリプトを生成。バイアス排除・再現性・比較可能性を確保。

## インタビュータイプ

| タイプ | 目的 | 対象 | 時間 | 質問数目安 |
|--------|------|------|------|-----------|
| `hiring` | 採用面接 | 候補者 | 45-60分 | 15-20問 |
| `user-research` | ユーザー調査 | 既存/潜在ユーザー | 30-45分 | 12-18問 |
| `stakeholder` | ステークホルダー | 経営・部門長・顧客 | 30-60分 | 10-15問 |
| `exit` | 退職・解約理由 | 退職者・解約ユーザー | 20-30分 | 8-12問 |
| `win-loss` | 受注/失注分析 | 成約/失注顧客 | 30-45分 | 12-18問 |

## JTBD質問構造

### 1. 状況・トリガー (Situation & Trigger)
- 「その日、何が起きましたか？最初に気づいたきっかけは？」
- 「それまでどう対処していましたか？ワークアラウンドは？」
- 「決断の瞬間、どんな感情でしたか？（焦り・不安・期待・諦め）」

### 2. 探索・評価 (Search & Evaluation)
- 「どのように解決策を探しましたか？情報源は？」
- 「比較検討した選択肢は？決め手は何でしたか？」
- 「不安・懸念はありましたか？どう解消しましたか？」

### 3. 採用・購買・導入 (Hiring & Onboarding)
- 「実際に使い始めてどうでしたか？最初の成功体験は？」
- 「想定外の障壁・学習コストはありましたか？」
- 「周囲(チーム/家族)の反応・巻き込みは？」

### 4. 継続・拡大・推奨 (Retention & Expansion)
- 「継続している理由・価値を感じる瞬間は？」
- 「機能要望・不満・改善してほしい点は？」
- 「他者に勧めるなら何と言いますか？誰に勧めますか？」

## スクリプトテンプレート (採用面接例)

```markdown
# 採用面接スクリプト: [役職名] - [候補者名]

## メタ情報
- **日時**: 2026-07-28 14:00-15:00
- **面接官**: [名前・役割]
- **候補者**: [名前・現職・応募動機]
- **評価基準**: [技術・カルチャー・ポテンシャル・コミュニケーション]

## オープニング (5分)
- 自己紹介・面接の流れ説明・リラックス誘導
- 「本日はお時間いただきありがとうございます。まずはリラックスして、ありのままお話しください」

## Phase 1: キャリア・動機 (JTBD: なぜ転職・なぜ弊社) [15分]
### Q1: 現職での「やりきった仕事」を教えてください
- **フォロー**: 「その時、どんな制約・プレッシャーがありましたか？」
- **評価**: 主体性・問題解決・成果定義

### Q2: 現職で「解決したかったができなかった課題」は？
- **フォロー**: 「なぜ解決できなかった？組織・技術・リソース？」
- **評価**: 現状認識・課題設定力・諦めない粘り

### Q3: 弊社を知ったきっかけ・応募決断の瞬間は？
- **フォロー**: 「他社と比較しましたか？決め手は？」
- **評価**: 企業理解・志望度・意思決定プロセス

## Phase 2: 技術・実務深掘り (JTBD: どう仕事を進めるか) [20分]
### Q4: 直近で最も難しかった技術課題・解決プロセス
- **フォロー**: 「仮説検証のサイクルは？誰とどう協働した？」
- **評価**: 技術力・論理的思考・協働・学習

### Q5: コードレビュー・設計議論で譲れない/妥協したポイント
- **フォロー**: 「具体例で。相手をどう説得・納得させた？」
- **評価**: 品質基準・コミュニケーション・影響力

### Q6: 知らない技術・領域にどうキャッチアップするか
- **フォロー**: 「最近学んだこと・学習プロセス・実践への応用」
- **評価**: 学習力・メタ認知・実践志向

## Phase 3: 行動・価値観 (JTBD: どう判断・振る舞うか) [15分]
### Q7: 意見対立・合意形成が必要だった場面
- **フォロー**: 「あなたの立場・相手の立場・落とし所」
- **評価**: 対立解決・心理的安全性・合意形成

### Q8: 失敗・ミスから学んだこと・再発防止策
- **フォロー**: 「誰にどう報告・謝罪した？プロセス改善は？」
- **評価**: 責任感・振り返り・システム思考

### Q9: 理想のチーム・マネージャー・働き方
- **フォロー**: 「弊社の文化・バリューで共感/懸念するところ」
- **評価**: カルチャーフィット・期待値調整・長期志向

## クロージング (5分)
- 逆質問タイム・次のステップ説明・感謝
- 「ご質問ありますか？選考フロー・タイムライン・オファー条件等」

## 評価シート (面接後即記入)
| 評価軸 | 5段階 | 根拠(具体的発言・行動) |
|--------|------|------------------------|
| 技術力 | 1-5 | |
| 問題解決 | 1-5 | |
| 学習・成長 | 1-5 | |
| コミュニケーション | 1-5 | |
| カルチャーフィット | 1-5 | |
| 主体性・オーナーシップ | 1-5 | |
| **総合判定** | **Strong Hire / Hire / No Hire / Strong No Hire** | |
```

## バイアス対策チェックリスト

| バイアス | 対策 |
|---------|------|
| **確証バイアス** | 事前仮説を書き出し・逆の証拠も探す |
| **ハロー効果** | 最初の印象で判断せず・全質問均等評価 |
| **親和性バイアス** | 共通点(出身・趣味)で評価歪めない |
| **直近効果** | 最後の回答過大評価せず・全体で判断 |
| **ステレオタイプ** | 属性(年齢・性別・大学)で仮定しない |

## コマンド

```

/interview-script --type=user-research --product="SaaSダッシュボード" --persona="PM"
/interview-script --type=stakeholder --project="システム刷新" --stakeholder="CTO"
/interview-script --template=custom --questions=questions.yaml
/interview-script --output=INTERVIEW_SCRIPT.md --format=markdown|notion|google-docs
/interview-script --bias-checklist --evaluation-sheet
```
