# /quiz-study - クイズ駆動型学習サイクル

## 概要
任意の学習コンテンツから**クイズを自動生成し、解答→即時フィードバック→解説→弱点特定→間隔反復スケジュール**までを一気通貫で実行。受動的読解を能動的想起に変換し、記憶定着率を劇的に向上。

## 学習サイクル

```
コンテンツ投入
    ↓
クイズ自動生成 (Bloomタクソノミー準拠)
    ↓
解答セッション (アダプティブ難易度)
    ↓
即時フィードバック + 詳細解説
    ↓
弱点分析・クラスタリング
    ↓
間隔反復スケジュール登録 (忘却曲線最適化)
    ↓
次回セッションで優先出題
```

## 使い方

```
/quiz-study                           # 対話式で開始
/quiz-study <コンテンツ>                # 直接指定で生成
/quiz-study --source=<ファイル/URL>      # ソース指定
/quiz-study --review                    # 復習モード (間隔反復キューから)
/quiz-study --weakness                  # 弱点特化モード
/quiz-study --stats                     # 学習統計表示
```

## クイズ生成エンジン

### Bloomのタクソノミー6段階対応

| レベル | 認知プロセス | 問題タイプ例 | 割合目安 |
|--------|------------|-------------|---------|
| **1. 記憶** | 事実想起 | 穴埋め・選択・用語定義 | 15% |
| **2. 理解** | 意味把握 | 言い換え・分類・要約・例示 | 20% |
| **3. 適用** | 手順実行 | パラメータ設定・API呼出・計算 | 25% |
| **4. 分析** | 構造分解 | 比較・因果・構成要素・論理検証 | 20% |
| **5. 評価** | 判断・批評 | トレードオフ・最適選択・妥当性判定 | 10% |
| **6. 創造** | 新規統合 | 設計・提案・改善案・統合問題 | 10% |

### 問題形式バリエーション

| 形式 | 適用レベル | 例 |
|------|-----------|-----|
| 穴埋め | 記憶・理解 | `Transformerのアテンション機構で__を計算する` |
| 選択式 | 記憶・理解・適用 | `最も適切な活性化関数は？` |
| 並び替え | 理解・適用 | `処理順序を正しく並べよ` |
| マッチング | 理解・分析 | `手法と特徴を結べ` |
| 短文記述 | 理解・分析・評価 | `なぜResNetで勾配消失が緩和されるか` |
| コード完成 | 適用・分析 | `この関数の__を実装せよ` |
| デバッグ | 分析・評価 | `このコードのバグを特定・修正せよ` |
| 設計提案 | 評価・創造 | `要件からアーキテクチャを設計せよ` |

## 適応的難易度制御

### IRT (項目反応理論) ベース

```
能力値θ 推定 → 次問題難易度b = θ ± 0.3logit
正解率目標: 70-80% (最適学習ゾーン)
```

### パラメータ
- **難易度 (b)**: 問題固有・IRT校正済み
- **識別度 (a)**: 弱学習者も強学習者も分離する力
- **推測度 (c)**: 選択式の当てずっぽう補正

### 更新ルール
```
正解 → θ += 学習率 × (1 - 正解確率) × a
不正解 → θ -= 学習率 × 正解確率 × a
```

## 間隔反復スケジューラ (SM-2改良版)

### 忘却曲線モデル
```
記憶保持率 R = exp(-t/S)
t: 経過日数, S: 安定性パラメータ (個人・教材別推定)
```

### 復習インターバル

| 反復回数 | 正解時 | 不正解時 |
|---------|-------|---------|
| 1 | 1日 | 10分 |
| 2 | 6日 | 1日 |
| 3 | 16日 | 3日 |
| 4 | 35日 | 7日 |
| 5+ | 2.5倍ずつ延長 | 半分に短縮 |

### 安定性・困難度更新
```
S_new = S_old × (1 + 0.1 × 易しさ評価)  (易しさ: 1=困難..5=容易)
D_new = D_old × (1 - 0.05 × 易しさ評価)
```

## 弱点分析・クラスタリング

### 分析軸
1. **認知レベル別**: 記憶/理解/適用/分析/評価/創造 別正解率
2. **トピック別**: キーワード・タグ・セクション別正解率
3. **問題形式別**: 形式別苦手傾向
4. **時間帯別**: 反応時間・時間経過劣化
5. **メタ認知ギャップ**: 自信度 vs 正解率 (過信・過小評価)

### 出力: 弱点レポート
```
## 弱点分析レポート (2026-07-27)

### Top 3 Weak Clusters
1. **Transformerアテンション計算の数学的導出** (分析レベル, 正解率33%)
   - 関連問題: Q12, Q18, Q24
   - 推奨: 数式手書き導出練習 / 3Blue1Brown視聴

2. **学習率スケジューラの選択基準** (評価レベル, 正解率40%)
   - 関連問題: Q7, Q31
   - 推奨: 比較表作成 / 実験ログ分析

3. **バッチ正規化の推論時挙動** (適用レベル, 正解率45%)
   - 関連問題: Q3, Q15
   - 推奨: 実装コードリーディング / 図解作成

### メタ認知ギャップ
- 過信傾向: 「自信あり」と答えた問題の正解率 52% (期待70%)
- 対策: 解答前確信度記録・事後検証習慣化
```

## 復習モード (`--review`)

```
/quiz-study --review --count=20 --mode=mixed
```

### モード
| モード | 内容 | 用途 |
|--------|------|------|
| `due` | 期日到来項目のみ | 日常復習 |
| `weak` | 弱点クラスタ優先 | 直前対策 |
| `mixed` | due 70% + weak 30% | 標準 |
| `cram` | 全項目シャッフル | 試験前詰め込み |
| `new` | 未学習・新規生成のみ | 新トピック |

## 統合連携

| ツール | 役割 |
|--------|------|
| `/studyflow` | 学習計画・セッション管理からクイズ呼出し |
| `/research` | 論文・技術調査結果からクイズ自動生成 |
| `/paper-read` | 論文スケルトン各セクションから問題生成 |
| `/write` | 学習ノート・要約から逆クイズ生成 |
| Obsidian | 知識グラフ上のノード→関連クイズ生成 |
| Anki/間隔反復 | 既存デッキ連携・インポート/エクスポート |

## オプション

| オプション | 説明 | デフォルト |
|-----------|------|-----------|
| `--source` | ソース (file/url/text/obsidian/topic) | 対話入力 |
| `--count` | 生成問題数 | 10 |
| `--bloom` | タクソノミーレベル指定 (1-6/all) | all |
| `--format` | 形式 (choice/fillin/short/code/design/mixed) | mixed |
| `--difficulty` | 難易度 (adaptive/easy/medium/hard) | adaptive |
| `--lang` | 言語 (ja/en) | ja |
| `--timer` | 制限時間/問 (秒) | なし |
| `--explain` | 解説詳細度 (brief/standard/deep) | standard |
| `--review` | 復習モードフラグ | false |
| `--weakness` | 弱点特化モード | false |
| `--output` | 出力先 (session/obsidian/anki/json) | session |

## 使用例

```
/quiz-study "Transformerアーキテクチャ" --count=15 --bloom=3,4,5
/quiz-study --source=./learned/transformer.md --format=code,design
/quiz-study --review --mode=mixed --count=20
/quiz-study --weakness --topic="attention" --output=anki
/quiz-study --stats --period=month --export=csv
```

## 学習効果指標 (追跡項目)

| 指標 | 目標 | 測定方法 |
|------|------|---------|
| **想起率** | ≥80% | 復習時正解率 |
| **転移率** | ≥60% | 未見問題への適用成功率 |
| **メタ認知精度** | 差≤10% | 自信度-正解率ギャップ |
| **学習効率** | ↑トレンド | 理解度/学習時間 |
| **長期保持** | 30日後≥70% | 遅延テスト |
