# /tool-discover — ツールディスカバリー + 外部検索案

使いたいツールがわからないとき、または「これに合うスキルある？」と思ったときに使う。
インストール済みスキル（`skills/*/SKILL.md`）を動的スキャンし、やりたいこととの関連度で候補を提示する。

## 使い方

```
/tool-discover ブックマークのURL一覧を作りたい
/tool-discover コードのセキュリティレビューして
/tool-discover セッション終了方法
/tool-discover PythonのGUIアプリを作りたい
```

やりたいことを natural language で書く。複雑でも短くても良い。

## どう動くか

1. `skills/*/SKILL.md` を全てスキャン（カタログはハードコードせず、その場の一覧から動的に構築）
2. クエリをトークン化（Western単語 + CJKニグラム）
3. 各スキルとの関連度をスコアリング
4. TOP3 を推荐理由付きで表示
5. スコア不足時は外部検索（任意連携）で代替を探索

## スコアリング

| 一致箇所 | スコア |
|----------|--------|
| ツール名完全一致 | +50 |
| トリガー・ニグラム一致 | +35 |
| ニグラム説明一致 | +25 |
| Western説明一致 | +20 |
| CJK単字一致 | +3 |
| 複数トークン一致ボーナス | +5~20 |

## 閾値ルール

- **80%以上**: ⭐ **確信度高い** — おすすめです
- **60-80%**: △ 候補ですが、意図と合っているかご確認ください
- **60%未満**: 💡 最高スコアが閾値を下回っています（代替検索を試みます）

## 外部検索（任意連携）

検索API のキーが環境変数（例: `TAVILY_API_KEY`）に設定されている場合、スコア不足時に自動で web search を実行し、GitHub/X/Reddit/HackerNews から代替ツールを探す。
キーがない場合は従来と同じ動作（代替案のみ提示）。
