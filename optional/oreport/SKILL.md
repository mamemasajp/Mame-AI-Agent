# /oreport

`oreport` スキルを実行します。

> これは **Claude Code 個人運用スキル**です（`optional/` 収録）。エージェント汎用の `skills/` とは異なり既定ではインストールされません。
> 収録内容は「秘密ゼロ・個人情報なし」方針に沿って、環境依存のツール名・パスを**汎用ロール**（例: `${MEMORY_MCP}`）やプレースホルダに抽象化しています。自分の環境の実値へ置き換えてください。詳細は [`optional/README.md`](../README.md) を参照。

**注意**: これは **オプション** です。単純なタスクでは `session-end` のみで十分です。
複雑なセッション（複数ファイル、新規機能実装、API設計、大規模改修）でのみ実行してください。

## セッション終了フロー（選択）

| セッション種別 | 実行コマンド |
|---------------|------------|
| 単純なタスク（typo修正、小規模修正） | `session-end` のみ |
| 複雑なセッション（複数ファイル、新規機能） | `session-end` → `oreport` |
| リファクタリング（仕様不変） | `session-end` のみ |

セッション終了の標準フローは `session-end` です。`oreport` は追加の議事録として、重要な意思決定や複雑な実装の記録に残す際に使用します。

## Phase 0-8 を順番に実行（スキップ不可）

> 各 Phase の「（例: …）」は環境依存の連携先の**役割**を表します。自分の環境のツール/MCP に読み替えてください。無い連携は該当 Phase をスキップして動作します。

1. **Phase 0: トークン最適化** — トークン計測・最適化ツール（例: token 最適化 MCP）でセッションのトークン利用を確認
2. **Phase 1: メモリ参照** — 記憶システム（例: 記憶 MCP / vault 検索）から関連コンテキストを参照
3. **Phase 2: Git操作** — commit + push 確認
4. **Phase 3: 検証実行** — L1/L2/L3（型・lint・テスト・整合性）
5. **Phase 4: たられば分析** — スキル・MCP 照合
6. **Phase 5: レポート生成** — 9+α項目を構造化
7. **Phase 6: 品質保証** — ライティングレビュー + 文章人間化ツール
8. **Phase 7: 記憶保存** — 記憶システム（例: 記憶 MCP / フィードバック MCP）へ保存
9. **Phase 8: フィードバックループ** — フィードバック昇格 + 次回リマインド

使用方法：

```
/oreport
```
